# 工具使用手册

> 适用：Agent 通路取证时加载。system prompt 里的工具手册段只有签名，
> 本规程是签名之外的实战用法——每条来自工具实现语义与 eval 实测。

## 一、选型决策（先选对再调用）

- 问**数字**（股价/营收/净利）→ 先 getDailyQuotes / getFinancialSummary 拿带时点的数；
- 问**文本段落**（业务、工艺、分红预案、经营讨论）→ searchAnnouncements；
- 复合问题分步组合：数字工具先行拿锚点，公告检索补叙述。

## 二、参数语义（易错点）

- `getDailyQuotes(code, from, to)`：from/to 是 ISO 日期（如 2024-01-01）。
  问"最近股价"时用**近一周区间**取最后交易日，禁止凭记忆报"现价"；
  区间拉全年返回量大，按需缩窄。
- `getFinancialSummary(code, fiscalYear)`：fiscalYear 是**会计年度**（如 2024），
  只有年度口径——问季度/半年数字它没有，转 searchAnnouncements 或如实说明缺口。
- `searchAnnouncements(query)`：query 写**完整问句**效果更好；
  带公司名 + 报告期最准（正例：「贵州茅台 2024 年度利润分配方案」）。

## 三、失败处理

- 返回"未覆盖/未找到"：换关键词重试一次（如去掉修饰词、换报告期表述），
  仍无则基于已获信息收尾并说明缺口——禁止编造补空。
- 工具报错文本（"抓取失败：…"）是给你的观察，不是给用户的答案——自我纠正后继续，
  不把报错原文写进终答。

## 四、调用经济

- 同参数重复调用同一工具 = 浪费步数（步数上限 6）；观察已够立即收尾。
- 每个数字的「来源/时点」字段在工具返回里已自带，终答原样带入，不得省略。
