# 年报横读规程

> 适用：问题涉及营收/净利/同比等财务指标时加载。每条规则都来自黄金集参照与 eval 实测病灶，不是泛泛常识。

## 一、收入口径先分清，禁止混用

- 「营业总收入」与「营业收入」是两个口径（实例：茅台 2024 年营业总收入 1,741.44 亿元
  vs 营业收入 1,708.99 亿元——前者含利息收入等，两者同比增速也不同：+15.66% vs +15.71%）。
- 用户问"营收"未指明时，默认用**营业总收入**口径并在答中写明口径名；
  两个数字不得互换、不得混排对比。

## 二、同比增速的出处纪律

- 年报「主要会计数据」段通常**直接披露**同比增减——优先引用披露值，不自己算。
- 确需自算时，分子分母必须**同口径同主体**（如两期都取营业总收入），并在答中注明
  "按 XX 口径计算"。
- 凡同比必带两期数值 + 口径 + 来源时点，禁止只甩一个百分比。

## 三、横读互验（主要会计数据 ↔ 合并报表）

- 关键指标（营收/归母净利）在「主要会计数据」与「合并利润表」两处都有，
  引用时以主要会计数据为准；两处数字不一致时如实说明差异，不擅自取舍。
- 归母净利润 ≠ 净利润（含少数股东损益）：用户问"净利润"未指明时默认**归母**口径并写明。

## 四、表述纪律

- 金额单位（亿元/万元）照抄披露值，不自行换算丢精度；
- 趋势判断（"持续增长"）需多年数据支撑，单期数据不引申趋势。
