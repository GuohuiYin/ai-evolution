## 背景（为什么做）

1. **生成评估的统计功效与检索侧同样不足**：生成黄金集 22 条（v1.2），
   M3 验收门③的失分模式分析、W14 冰淇淋期望重审都压在个位数样本的类别上；
   Judge 本身只有"锚定 5/5"的一次性校准，无一致率持续证据——蓝图验收口径
   "Judge 与人工抽检一致率 ≥80%"至今未测量。
2. **能力地图两份论述挂账到归期**：引用忠实度强化、内容审核（moderation）论述补章
   （advanced README W17-18 行登记，自有语料风险低但标准答案应有章节）。
3. **轮换机制欠账**：W17 造数规范第四条挂账"轮换窗口与退役纪律待 W18 随扩容规模定稿"。
