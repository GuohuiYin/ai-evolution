## 对照实验设计要点（裁决口径预先写死）

1. **主对照用各自默认满维**（bge-m3 1024 vs Qwen3-8B 4096）：生产选型选的是模型不是维度，
   满维是各自厂商推荐形态；Qwen3 缩至 1024 维作**敏感性参考**附记，不进主裁决
2. **变量唯一**：语料、分块参数（W13 裁决档）、hybrid 开关、rrf-k=60、recall-top-k=20、
   黄金集 29 条全部冻结，只换 embedding 模型与对应 collection
3. **两轮跑法**：bge-m3 基线轮数据在案（W13，93%）不重复跑，除非设施变更；
   Qwen3 轮新建 collection 全量重建；两轮各附成本实测（token 账，不引用刊例价替代实测）
4. **裁决规则**：Recall@5 提升 ≥2pp 才谈切换（±0.5 噪声带 ×29 条 ≈ ±1.7pp，小于此视为打平）；
   打平则保持 bge-m3（现状优先，零切换成本）；下降则保持并记录
