# M3 计划概要：最小 Loop 收官（W10-W13）

> 对应 PPT Slide 19。细节计划在各周开工前细化。
> 前置铁律：L1-L3 未达标不进 L4——没有 Harness 的 Loop 等于没有刹车的自动驾驶。

## 周主题与核心交付

| 周 | 主题 | 核心交付 |
|---|---|---|
| W10 | L4 Loop 精读 + P3-1 | **最小研究 Loop**：拉行情/财务 → 提假设 → 查公告验证/证伪 → 出报告；**迭代次数 + Token 预算双上限**（本层灵魂） |
| W11 | P3 护栏与持久化 | 审批断点（生成"买入倾向"挂起人工确认）、熔断、checkpoint（Spring 状态机 + DB）、免责声明强制输出 |
| W12 | 端到端收官 | 3 个场景录屏；架构总结文（部署已超前完成，容量让位给录屏与写作） |
| W13 | 分享 + 复盘 | 30 分钟内部分享（PPT v2：框架+实测）；更新认知地图；制定进阶期计划 |
