# W13 计划：检索质量攻坚周（两阶段化）+ M3 验收

> 对应 M3 阶段索引 W13 行。主题：召回/精排分层——生产级检索范式本体。

## 背景（为什么做）

当前检索单阶段：topK=5 + 阈值 0.5 一刀切（Recall@5=72%）。生产级是两阶段：
宽松召回（混合检索，topK 放大）→ reranker 精排取前 N。混合检索解决"没捞回来"
（字面匹配类失分，5 条证据），rerank 解决"捞回来排错位/压线误杀"（boundary 类）。
两者均走黄金集数据裁决，不达标不启用（同 few-shot 裁决机制）。
