## 当日追加：W12 #2 API Key 鉴权（review 前一次过）

- **核心实现**：`ApiKeyAuthFilter`（infra 域，OncePerRequestFilter）——默认拒绝 + 显式放行清单
  （`/`、index.html、favicon、swagger-ui、v3/api-docs、actuator/health/**；metrics/info 持证），
  `X-API-Key` 常量时间比对（MessageDigest.isEqual 防时序侧信道），401 返回 ProblemDetail（B3 同格式），
  空 key 构造即抛（fail-fast，鉴权没有"忘记开"的静默中间态）
- **有意不标 @Component**：只经 FilterRegistrationBean 注册（顺序 HIGHEST_PRECEDENCE+1，排在
  TraceIdFilter 之后——401 日志也带 traceId），@WebMvcTest 切片零污染
- **OpenAPI（#2b，A7）**：`@SecurityScheme` apiKey + 全局 SecurityRequirement；Swagger UI
  Authorize 按钮输入 key 后调试请求自动带头——文档页放行但调试不放行；ApiDocsTest 断言锁定
- **生态对齐**：6 个上下文测试配 `ai.security.api-key=test-key`；McpServerIT 全链路改持证 +
  新增无 key 401 集成用例；eval workflow 补 `AI_MCP_CLIENT_ENABLED=false` + 占位 key
  （**顺手修掉 #1a 埋的 CI 隐患**：runner 无 uvx 会起不来）；对话页首次发送 prompt 输入 key
  （sessionStorage 关页即清，401 自动重问）；k8s README secret 命令 + README MCP 客户端说明同步；
  本地 .env 已生成随机开发 key（gitignored）
