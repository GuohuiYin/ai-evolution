# W5 周记（2026-09-05）

## 做了什么

- Function Calling 三件套：行情/财务/公告检索工具 + `/ai/agent` 端点，模型自主调度
- 工具层 Harness：AOP 审计切面（tool-audit 留痕）+ RFC 7807 错误契约
- **M1 验收门正式通过**：黄金集 20→21 条三类别分层，Recall@5 = 86.7%（≥0.7），报告归档
- PDF 摄入 + 元数据规范：真实年报入库 303 分块，`KnowledgeFilter` 过滤检索
- 工程防线升级：A11 设计自检三问 / A12 红线单点化 / A9 子域前置拆分 / ArchUnit 自动拦截 / ADR 补齐 0004-0008

## 卡在哪（本周素材丰富）

1. **402 余额不足**：SiliconFlow 未充值，异常翻译层为它补了 OpenAI 兼容通道的专门处理
2. **别名漂移**：模型名凭记忆写会 4xx，必须以控制台当前别名为准（ADR-0005 留痕）
3. **PromptTemplate 大括号陷阱**：StringTemplate 引擎把模板内字面 JSON `{}` 当占位符，需 `\{` 转义
4. **验收门先红后绿**：年报入库后 Recall 从 86% 跌到 60%——不是检索退化，是"唯一正确答案"假设失效，逼出黄金集多源语义（expectSources）。验收门的价值就在它敢红
5. **人肉 review 抓出结构债**：topK 散落、similaritySearch 三处重复、免责声明漂移——全部沉淀为规范 + ArchUnit 自动护栏，不再依赖人肉
