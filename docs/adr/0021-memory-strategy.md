# ADR-0021:记忆策略——向量记忆起步,schema 预留事实结构,读写分离 + 可治理

- 状态:已接受
- 日期:2026-10-29

## 背景

ADR-0015 解决了会话内工作记忆(手工读写窗口历史,替代 `MessageChatMemoryAdvisor` 的重复追加),但跨会话记忆仍是空白:Agent 无法记住用户偏好、历史任务结论、过往失败教训。业界 2025-2026 已形成事实标准(ChatGPT/Claude memory 的公开形态 + Mem0/Zep/LangMem/Letta 等框架):读写分离、LLM 抽取原子事实、注入有预算、用户可治理。需要为本项目选定一条与现有基建(Qdrant、异步任务、OTel)复用度最高的路线。

记忆三层模型:工作记忆(当前窗口,ADR-0015 已覆盖)、情景记忆(发生过的事)、语义记忆(沉淀的事实与偏好)。本决策只管后两层的持久化。

## 决策

1. **向量记忆(L2)起步,schema 预留事实结构(L3)**:记忆条目以 `subject / fact / confidence / valid_from / superseded_by / source_trace_id` 结构入 Qdrant,embedding 检索召回;`superseded_by` 字段一期不启用,但为事实冲突消解(新事实覆盖旧事实)留路——避免平铺向量库日后推倒重建。
2. **读写分离**:
   - 写路径异步:会话结束后后台任务调 LLM 抽取候选事实 → 与存量比对 → 新增/更新/跳过;不阻塞对话主链路(与 ADR-0018 语言策略一致,抽取管线可作离线/服务化候选)。
   - 读路径同步注入:每轮 system prompt 组装 = 用户画像(常驻,手写/确认) + 按当前 query 检索 top-k 相关记忆 + 会话窗口;k 有硬预算(默认 ≤5 条),防记忆污染稀释注意力。
3. **治理红线**:记忆按 user 硬隔离;用户可见、可删;敏感信息(凭据、隐私)不沉淀;每条记忆携带 `source_trace_id` 可回溯到产生它的那次会话(接 ADR 观测体系,OTel 记录每次记忆读写)。
4. **记忆纳入评估**:抽取准确率与注入相关性进黄金集双轨评估(ADR-0007),错误记忆视为质量事故而非功能瑕疵。
5. **明确不做**:一期不上时序知识图谱(Zep/Graphiti 路线);不引入专用记忆框架(Mem0/LangMem),抽取逻辑自研保持与 ReAct 手工循环同等的可控性。

## 备选方案

- 会话存档 + 全文检索(纯 L1):跨会话"记不住事",捞回原文非知识。否决。
- 直接上时序知识图谱(L4):事实演化表达最强,但复杂度与团队现阶段不匹配;schema 预留的 `valid_from/superseded_by` 是未来升级的桥。暂缓。
- 引入 Mem0/LangMem 框架:开箱即用但抽取与治理逻辑成为黑盒,违背手工循环建立的可控性立场(ADR-0015 同旨)。否决,保持关注。

## 后果

- 正:跨会话记忆从 0 到 1 且全程可观测、可治理、可评估;Qdrant/异步任务/OTel 三大件零新增依赖;schema 一期到位避免重构。
- 负/权衡:抽取管线是新故障面(抽取幻觉会写入错误记忆)——由决策 4 的评估门禁对冲;向量召回在无冲突消解时可能同时返回过期与现行事实,一期靠 `valid_from` 排序缓解。
- 待办:记忆条目的 PII 过滤规则随首个真实用户场景成文;`superseded_by` 冲突消解启用时机由 eval 数据决定。
