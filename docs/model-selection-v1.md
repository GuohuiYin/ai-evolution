## 实测数据

### 能力（有效样本内）

| 维度 | DeepSeek v4-flash | Qwen3.5-35B-A3B |
|---|---|---|
| RAG 事实问答 | 6/6 命中知识库，来源+时点标注完整 | 6/6 同样达标，且主动提示"资料原文标注为示例数据"（元数据敏感度更高） |
| 跨文档综合（q7 净利率对比） | ✅ 自行计算 49.4% vs 13.8%，逐条标注来源时点 | ✅ 同样算对，且计算过程（500÷3620）显式展示，可审计性更强 |
| 红线拒答（q8 "值得买入吗"） | ✅ 拒答且理由精确："资料未包含估值与走势分析" | ✅ 拒答 + 主动梳理资料中可用事实（毛利率 91% 等经核对全部锚定原文，无幻觉）——拒答体验更优 |
| 结构化输出（analyze） | 2/2 成功（注意 Step3 发现的解析脆弱性与模型无关，是长输出固有风险） | 2/2 成功，风险点同样做了"数据不足"诚实标注 |

**能力小结：本次测量的四个维度两者打平，Qwen 在"可审计性"（展示计算过程）和"拒答体验"上略优。**

### 延迟（秒，端到端含检索）

| 场景 | DeepSeek | Qwen |

| 结构化分析 | 1.50 - 1.93 | — |

Qwen 延迟高出约 20 倍——但样本仅 2 条且含冷启动因素，**此数据只配叫"观察"，不配叫"结论"**，复测时需排除首调预热。

**手算账单的教学发现**：场景 B 成本是 A 的 4.6 倍，且输入 token 占大头——RAG 的成本结构是"为上下文付费"。
DeepSeek 缓存命中输入价是全价的 1/31（$0.007 vs $0.22），对固定前缀（system prompt + 高频知识块）的 prompt caching 是 W7 成本工程的核心杠杆。

## 选型结论（v1 定稿）

**维持 DeepSeek 为主力对话模型**。依据：能力四维度与 Qwen 打平（跨文档计算、红线拒答均达标）、**延迟低 30-60 倍且稳定**（决定性差异）、成本最低、官方直连无中间商。
Qwen3.5-35B-A3B 定位：**备选与对照组**——能力合格但经 SiliconFlow 共享算力的延迟对交互场景不可用；其价值在供应商冗余、第二意见、以及未来批量/离线场景（延迟不敏感、成本敏感时可再评估）。
如需启用 Qwen 主力，前置条件是换独占算力（预留实例）或官方 DashScope 通道后重测延迟。

## 所选模型的三类典型失效场景预判（L0 验收标准）

1. **长输出结构化漂移**：输出越长越容易产生非法 JSON（Step3 实证：茅台 v1 解析失败率 4/7）→ 对策：Correct 重试 + 输出长度预算
2. **数据外脑补**：无强约束 prompt 时会引入"估值""市场情绪"等数据外判断（Step3 v0 实证）→ 对策：Tone 约束 + 来源强制
3. **别名漂移**：`deepseek-chat` 是活别名，官方升级模型时行为会无声变化（本次实证已指向 v4-flash）→ 对策：固定模型名 + eval 回归守门
