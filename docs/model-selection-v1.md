**手算账单的教学发现**：场景 B 成本是 A 的 4.6 倍，且输入 token 占大头——RAG 的成本结构是"为上下文付费"。
DeepSeek 缓存命中输入价是全价的 1/31（$0.007 vs $0.22），对固定前缀（system prompt + 高频知识块）的 prompt caching 是 W7 成本工程的核心杠杆。

## 选型结论（v1，待 Qwen 复测校准）

**维持 DeepSeek 为主力对话模型**。依据：能力在全部场景达标（含跨文档计算与红线拒答这两个硬场景）、延迟低一个数量级、成本最低、官方直连无中间商。
Qwen3.5-35B-A3B 定位备选/对照组——其价值在"第二意见"与供应商冗余，不在主力替换。

## 所选模型的三类典型失效场景预判（L0 验收标准）

1. **长输出结构化漂移**：输出越长越容易产生非法 JSON（Step3 实证：茅台 v1 解析失败率 4/7）→ 对策：Correct 重试 + 输出长度预算
2. **数据外脑补**：无强约束 prompt 时会引入"估值""市场情绪"等数据外判断（Step3 v0 实证）→ 对策：Tone 约束 + 来源强制
3. **别名漂移**：`deepseek-chat` 是活别名，官方升级模型时行为会无声变化（本次实证已指向 v4-flash）→ 对策：固定模型名 + eval 回归守门
