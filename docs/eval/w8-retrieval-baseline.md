# W8 检索评估基线（39 条黄金集，真实 bge-m3）

> 2026-09-09 本地跑批，`AI_EVAL_ENABLED=true`，Recall@5 / 阈值 0.5。黄金集从 21 条扩到 39 条，
> 新增 paraphrase（问法敏感性）与 literal（字面型）两类。本文档是"评估揭示弱点"的实证档案。

## 总览

| 类别 | 通过率 | 说明 |
|---|---|---|
| normal | 14/15 | 唯一失败见下（12987） |
| paraphrase | 2/4 | 12987 三个换问全部未召回 |
| literal | 2/4 | 原文片段式查询过半失败 |
| boundary | 3/6 | 间接指代问法（"谁""这两家"）失败 |
| adversarial | 8/10 | 两个"失败"中一个实为误分类 |
| **正例 Recall@5** | **21/29（72%）** | M1 门（≥0.7）通过 |
| 负例拒答率 | 8/10 | — |

## 失败模式分析（按根因归类）

### 模式一：数字/代号语义盲区（3 条）→ 混合检索候选

`12987 工艺的具体含义` / `12987是什么` / `12987 每个数字代表什么` 全部未召回。
语义向量对纯数字代号几乎无区分度——这类 query 是关键词检索的主场。
**这是"是否需要混合检索（向量 + BM25/关键词）"最直接的量化证据。**

### 模式二：原文片段式查询反而不中（2 条）→ 同上

`赤水河流域环境容量约束` / `SNE Research 口径 37%` 是语料原文，向量相似度却低于阈值 0.5。
短 query 缺上下文语义，向量得分被稀释。同样指向混合检索。

### 模式三：指代消解超出检索层能力（3 条）→ 查询改写候选

`谁的风险和原材料价格关系最大` / `这两家公司里谁的品牌壁垒更厚` / `碳酸锂价格波动会影响谁`
——"谁"需要对话上下文或多步推理，单次向量检索无解。
这是 W9+/M3 查询改写（query rewrite / HyDE）的候选，不该靠调阈值硬救。

### 模式四：误分类（1 条）→ 移交 W8-4

`宁德时代的股票现在值得买入吗` 检索命中 catl.md——**检索行为完全正确**（话题相关），
它的正确行为是"命中后生成层拒答给买卖建议"。红线遵循属生成评估，W8-4 生成黄金集收编。

### 模式五：真·近域陷阱（1 条）→ 已知局限，保持监控

`五粮液的营收规模有多大` 召回了茅台年报（同为白酒，向量天然相近）。
语义检索的固有边界；缓解方向是元数据过滤（股票代码入 payload）而非阈值。

## 本轮结论

1. 混合检索值得做——模式一+二共 5 条直接证据，列入 M3 候选（实现留待裁决，本周只取证）
2. 阈值 0.5 不动：模式三/五不是阈值能救的，调阈值会牺牲 adversarial 通过率
3. 黄金集扩充流程本身有效：第一轮跑批就抓到 2 条标注错误（漏标 PDF 源），已修正
