## 旧案降分归因：三大机制，零能力性回归

经 R2 双轮复跑 + 校准人工复核，v2.1→v3 的全部显著降分归入三机制：

**机制① Thought 泄漏缺陷集中爆发（在案缺陷，W19+ 候选——优先级建议上调）**

- F3 分红比例 40.21%（6→2/3）：最终答案是 ReAct 中间思考步（"Thought: 年报已披露
  …故换关键词再检索一次"），judge 判词"仅展示检索过程"吻合——泄漏现场
- 校准抽测 10 案中 5 案最终答案带 "Thought:/思考：" 前缀（2024 净利分红/600519 工艺/
  一季度/冰淇淋/G2）——**缺陷在最终答案层面的批量证据**
- judge 对这些泄漏的 compliance/accuracy 扣罚系统性偏松（见末章），故 judge 低分案
  （C2 分红时间线 3/4、M4 2/2、U3 电商 2/6 等）维持挂账原判，不因 judge 水位改判

**机制② 速览锚点召回挤压（语料 3→8 源的结构效应）**

- M3 第二增长曲线追问（→2/3）：检索被 C25 年报 chunk 占据，速览"储能=第二增长曲线"
  锚点未进视野；模型拘泥"年报未使用'第二增长曲线'一词"而诚实拒答——措辞拘泥+召回
  偏移，G1、储能 R2 同族
- CP 基酒产能+约束（6→4/4 两轮稳定）：产能数字答对，赤水河约束（速览锚点）两轮遗漏——
  与检索侧 12987/取酒轮次抖动同因（年报工艺 chunk 挤压速览）
- 检索侧联动线索：retrieval v5 复跑显示同类擦边案抖动（12987 ❌✅❌、取酒轮次 ✅❌✅），
  生成侧是其下游表现。**裁决候选（W20+）：速览 md 的 chunk 加权或 docType 过滤在
  compound/解释类 query 的适用性实验——不夹带本周**

**机制③ 参照答案时效（轮换首演的核心猎物，2 案+3 修正已落地）**

- **F4 法定代表人真值反转**：2024 年报=张德芹，2025 年报 p5 与 2026 半年报 p4/p110
  =陈华（pypdf 三份取证）。模型答"陈华"并引 2025/2026H1 来源完全正确，judge 拿过期
  参照判 0/0/0 并称"编造来源"。**参照已重锚定**（Owner 裁决①，轮换纪律"参照推翻"
  条款首次启用）——本案从"v2.1 挂账+v3 加重"改写为"模型正确适应新语料，黄金集滞后"
- **M7 中期分红算期望重审**（Owner 裁决②）：原参照"中期不计入 40.21%"断言无 chunk
  可证，模型诚实声明"无法确认"获人工满分——期望工程修正已落地（W14 冰淇淋先例）
- 本轮已前置修正 3 案：2025 一季度（理由句失效）、固态电池（在研≠量产边界硬化）、
  冰淇淋占比（2025 年报起注释消失）
