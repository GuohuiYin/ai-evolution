# 黄金集造数规范（专项二·评估造数 W17 第一刀）

> 2026-10-10 立。黄金集是全部分析裁决的标尺（W13/W15/W16 每次切换都压在它上面），
> 标尺本身的造数必须有规范：每条用例可溯源、类别定义单一事实源、变更先登记后提交。
> 适用：`eval/golden-set.json`（检索）与 `eval/golden-set-generation.json`（生成，W18 扩容时同规）。

## 一、五类定义（检索集）

| 类别 | 定义 | 靶子 |
|---|---|---|
| normal | 语料主体的常规事实问句，语料中有直接答案 | dense 主路基本功 |
| paraphrase | 同一事实的换说法/换角度（不同义改写、口语化） | 语义泛化，不靠字面 |
| literal | 原文片段/代号/数字串级查询 | sparse 字面路（W8/W13 病灶类） |
| boundary | 双实体比较、需要综合或多跳的问句 | 改写 + 召回 + 融合的衔接缝 |
| adversarial | 域外请求，期望**不召回**（expectSources=null） | 误召回防线（阈值 + sparse 裁决） |

## 二、锚定规则（每条必须挂证据）

1. **正例字面锚定语料**：答案必须真实存在于语料（文件 + 行/段落可查）；数值类以
   公开年报口径为准并注明。禁止"我觉得语料里有"——造数时当场 grep/翻阅验证。
2. **expectSources 最小集**：答案在多个源都有时才列多源；只有 PDF 有的不挂 md，反之亦然。
3. **adversarial 锚定"语料无"**：当场确认语料（含 PDF 全文）确实无相关内容，
   防止把可答案错标成拒答案。

## 三、adversarial 分层（W16 证据驱动）

- **泛域外层**：与语料领域零词面重叠（天气/就医/菜谱等）——现状防线应拒，入库即守线。
- **近似域外层**：同行业竞品、投资建议、语料主体的域外侧面、**金融通用词面**
  （"价格/走势/行情"类——W17 v4 首跑实证："黄金价格走势"dense 0.53 误召回）、
  含域外数字标识符的查询（"2026 世界杯"被 sparse 标识符网捞起）——
  **W15/W16/W17 实测的已知失败面**（dense 交叠带 0.50-0.60 误召回）。
  此类用例按**挂账在集**处理（与正例挂账案同一先例：品牌壁垒/赤水河/五粮液均在集）：
  可以入库，但必须在 changelog 与基线报告中显式标注"已知失败挂账 + 机制判读"，
  防线升级（阈值/召回门槛/域外拒答）的 PR 以这些案转绿为验收证据。
  当前失败面清单见 [w17-golden-v4-baseline](retrieval/w17-golden-v4-baseline.md)、
  [w16-topscore-distribution](retrieval/w16-topscore-distribution.md) 与
  [w16-sparse-bm25-eval](retrieval/w16-sparse-bm25-eval.md)。

## 四、防泄漏机制

1. **与 prompt 例句隔离**：用例措辞不得复用 `resources/prompts/` 任何模板例句/few-shot
   措辞——模型"背过答案"的评估是无效评估。造数时 grep prompts 目录自查。
2. **用例间去重**：新案与既有案的 query 做字面与语义双重比对，近重复述同一事实的不收
   （paraphrase 类的价值在"换说法"，不是"同义句 N 个变体刷数"）。
3. **定期轮换**（挂账机制项）：黄金集长期固定会诱发隐性过拟合（调参对着固定 39 条调）。
   轮换窗口与退役纪律待 W18 随扩容规模一并定稿。

## 五、变更流程（纪律）

1. **先登记后提交**：任何增删改先在 [golden-set-changelog](golden-set-changelog.md)
   登记版本行（变更内容 + 对应基线报告），再提交数据集。
2. **全量复跑零回归**：新增案真实 eval 复跑——旧案零回归；新正例案全过；
   新 adversarial 案全拒（未过则按第三条分层规则处理，不静默改期望）。
3. **类别配比披露**：每次扩容在 changelog 注明五类数量——配比的任何漂移可追溯。
