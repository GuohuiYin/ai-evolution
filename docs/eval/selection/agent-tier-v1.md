# Agent 通路定档实验 v1：deepseek-v4-flash vs deepseek-v4-pro

- 日期：2026-10-29
- 目的：W25 #3 模型路由的定档依据（裁决②：规则先行，实测数据作调参依据顺带产出）
- 机制：`ModelTierAdvisor`（#3-i）按通路切档；pro 臂经 `AI_MODEL_TIER_AGENT=deepseek-v4-pro` 起服
- 样本：planner-tier-v1 同族 10 案（跨实验可对照）；脚本 `scripts/agent_tier_experiment.py`
- 计量：token/调用次数读 #2 台账增量（成本工程产物的首个消费场景）；延迟为端到端
- 样本文件：`agent-tier-v1-flash.json` / `agent-tier-v1-pro.json`

## 一、路由分组（本实验的副产品：分档选择性实证）

10 案中 6 案命中 AGENT 通路（股票代码/净利/营收关键词），4 案走 RAG（对照组）。
pro 臂上 RAG 四案模型仍为 flash——分档只切目标通路，不误伤邻路，机制选择性成立。

## 二、性能数据（agent 通路 6 案合计）

| 指标 | flash 臂 | pro 臂 | 倍数 |
|---|---|---|---|
| 端到端总耗时 | **45.9 s** | 259.0 s | **5.6x** |
| prompt tokens | 34,742 | 33,850 | ≈1x |
| completion tokens | **6,296** | 15,329 | **2.4x**（pro 思考 token 计入输出计费） |
| 逐案延迟区间 | 2.0–11.7 s | 6.8–108.3 s | — |

按官方价目（V4-Pro 输入/输出约为 Flash 的 12 倍档）估算，agent 通路单次问答成本升档后约 **15–20 倍**。
RAG 对照组两臂数据基本持平（8034/4777 vs 7981/3564 token，34.2s vs 27.1s），无污染。

## 三、逐案质量对照（人工评）

| # | 案例 | 判定 |
|---|---|---|
| 0 | 茅台 2025 归母净利 | 平：数值一致（823.20 亿），flash 多给同比/扣非等纵深，pro 精确作答更简 |
| 2 | 茅台 2024 净利+分红 | 平：数值与预案一致（862.28 亿 / 10 派 276.24 元），pro 多捕捉一笔 2024-12 已实施分红 |
| 3 | 600519 营收+工艺 | 平偏 pro：数值一致，pro 的工艺描述更细（30 道工序/165 个环节等年报原文） |
| 4 | 宁德净利+市占率 | 平：507.45 亿 / 37.9% 双臂一致，来源标注都规范 |
| 6 | 它的净利润呢（缺指代） | 平：双臂都正确反问查询对象，红线行为一致 |
| 7 | 冰淇淋营收占比（域内不可答） | 平：双臂都如实答「未单独披露」并给合并口径 0.17%，诚实红线一致 |

质量小结：6 案双臂**事实面零分歧**，红线行为（缺指代反问、不可答如实拒）完全一致。
pro 的收益仅在叙述风格（更简洁）与个别细节覆盖，无正确性差。

## 四、定档结论

**Agent 通路不升档，分档机制备而不用（默认全空档）。**

1. 质量：flash 在本样本已达天花板（6/6 与 pro 打平），无升档的质量收益证据——
   与 planner-tier-v1「不留高档位入口」结论互证。
2. 成本：升档代价 15–20 倍成本 + 5.6 倍延迟，买不来正确性。
3. 机制价值仍在：分档能力已上线可关可切，若未来接入更难任务类型（深度研究/长链推理）
   或 flash 出现质量退化信号（eval 回归守门），改一行配置即可升档，台账 byModel 即时量化。

## 五、后续注意

- pro 的 completion 计费含思考 token（案 7：6256 token 产出与 flash 997 token 的回答等长），
  成本敏感场景下 pro 类思考档的「隐性放大」需在预算口径中留意（当前熔断口径 prompt+completion
  已天然覆盖）。
- 多轮案（5/6）双臂共用同构会话（彼此互为上下文），横向对照有效，绝对质量不作判据。
