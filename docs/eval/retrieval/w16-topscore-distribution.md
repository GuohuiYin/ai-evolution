## 校准判读（阈值 0.5 的第一份分布证据）

1. **正例通过组 27 条全部 ≥ 0.51**，median≈0.66——阈值 0.5 已紧贴正例分布下限，
   现状处于"再放低无收益（负例该拒的已拒）、再抬高必误杀"的位置。
2. **交叠带实测存在，调阈值是负交换比**：误召回组 {0.50, 0.55, 0.60} 与通过组低段
   {0.51, 0.52, 0.53, 0.53, 0.55, 0.57, 0.57, 0.58}（8 条）高度交叠。两档推演：
   - 阈值提到 0.61：切掉全部 3 条误召回，但误杀 8 条正例 → Recall 19/29（66%），跌破 M1 门；
   - 阈值提到 0.56：切掉 2 条误召回，误杀 5 条正例 → 22/29（76%），5 正例换 2 负例仍净亏。
   **结论：阈值 0.5 维持不动——第一次不是"拍的经验值"，而是有分布数据支撑的裁决。**
3. **残余失败的分数形态指向"非阈值病灶"**：3 条误召回最低分 0.50 恰压阈值线（比亚迪案），
   属"语义相近但越界"的分布尾部；2 条正例未通过中 1 条（赤水河）以 0.64 误中年报——
   分数不低、对手更强，是排序层病灶，与 W15 判读一致。
4. **品牌壁垒案失败形态本轮变为"未召回"（缺席）**：改写后"贵州茅台和宁德时代哪家的
   品牌壁垒更厚"在 dense 段阈值下零命中，且 hybrid 的 sparse MatchText 路同样无候选
   （否则 RRF 必有输出）。对 W16 #2 取证的直接含义：**该案两路现状均无救，恰是
   "真 BM25 稀疏权重查询"可解性验证的理想靶子**——#2 第一刀手工构造查询即以此案为先。
