# W15 Embedding 模型对照裁决报告（bge-m3 vs Qwen3-Embedding-8B）

> W15 #1。切换门槛（计划写死）：Recall@5 提升 **≥2pp** 才谈切换，打平保持 bge-m3。
> 两臂完全同口径：同一黄金集 29 正例 + 10 负例、hybrid 开、rrf-k=60、recall-top-k=20、
> 阈值 0.5、检索 eval 走改写层（W15 #2 起口径）。

## 设施改造（前置，`cfb0d0d`）

向量签名元组扩为 `chunk-size|ft|emb:MODEL|col:COLLECTION`，`application.yml` 的
`embedding.model` 支持 `AI_EMBEDDING_MODEL` env 覆盖——**换模型/换 collection 自动
全量重建，零手工清库**。两条新契约测试锁死判变行为。B 臂全程即用此设施：
env 覆盖后 initialize-schema 自动建 4096 维 collection、签名不符自动重建，无需任何人工干预。

## 总体对照（2026-09-29 复跑）

| 指标 | A 臂：BAAI/bge-m3（1024 维） | B 臂：Qwen/Qwen3-Embedding-8B（4096 维） | Δ |
|---|---|---|---|
| 正例 Recall@5 | **27/29（93.1%）** | 25/29（86.2%） | **−6.9pp** |
| 负例拒答率 | 7/10 | **9/10** | +2 条 |
| M1 验收门（≥0.7） | 通过 | 通过 | — |
| 全量重建耗时（3 文件） | **17s** | 423s（≈7min） | **慢约 24 倍** |

| 宁德时代的股票现在值得买入吗 | adversarial | 拒答成功（A 臂误召回 catl.md） |

**恶化 3 条（A✓→B✗）：**

| 案例 | 类别 | B 臂失败形态 |
|---|---|---|
| 飞天茅台是哪个公司的产品 | normal | 改写展开"是贵州茅台还是宁德时代的产品"后 Top1 落年报而非 maotai.md |

**共同失败 2 条：** 品牌壁垒更厚（boundary，挂账观察项）、五粮液营收（adversarial 误召回茅台年报）。

**形态观察：** B 臂 3 条 boundary 失败 Top1 全部落同一份茅台年报——双实体锚定查询下
Qwen3 对"年报"类长文档呈现偏置；负例拒答更好（9/10）说明其相似度分布整体更低、
更"保守"，与正例 Recall 走低互为印证。

## 成本与运维

| 项 | A 臂 | B 臂 |
|---|---|---|
| 摄入 token 计量 | 不可得（embedding 调用未经 TokenUsageAdvisor，两臂同缺） | 同左 |
| 重建墙钟（3 文件） | 17s | 423s |
| API 定价 | bge-m3（W12 选型时调研：SiliconFlow 免费档） | $0.04/M tokens（W15 选型调研） |
| 向量维度/存储 | 1024 | 4096（4 倍存储） |

**topScore 分布注记：** 检索层未外暴露逐案分数，本报告以负例拒答率作分布校准的
间接证据；逐案 topScore 采集列入后续 eval 设施候选改进。

## 裁决结论

- **保持 BAAI/bge-m3，不切换。** Qwen3-8B 正例 Recall −6.9pp（远超 2pp 门槛的负方向），
  摄入慢约 24 倍、存储 4 倍，无任何一维优势可抵消
- Qwen3 的两点收益（literal +1、负例拒答 +2）不改变裁决，但**赤水河案被修复**提示
  该案属"embedding 语义粒度"敏感型，留作排序层/挂账观察的交叉证据
- 设施改造（签名并入 emb/col 判变键）是本任务独立于模型结论的持久收益：
  今后任何 embedding 模型/库变更自动触发重建，杜绝脏向量
