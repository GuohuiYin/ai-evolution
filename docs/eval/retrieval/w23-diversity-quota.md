# W23 #2 检索主体多样性收官报告（2026-10-26）

## 病灶与机制

**病灶（W22 #3a 实锤）**：双主体查询「宁德时代和贵州茅台哪个更值得长期持有」召回池 20 条里
茅台片段 0 条（buckets=[0,20]，池级垄断），裸截 top-5 全被宁德时代年报片段垄断，
红线拒答只能说「资料未覆盖」——回答正确但上下文天然偏科。

**机制（裁决②方案 A：召回后配额重排 + 缺口锚定补召）**：

- `SubjectExtractor`：词典制主体识别（规范名/别名/股票代码，大小写不敏感）
- `RetrievalDiversityGuard`：查询提到 ≥2 个在库主体时，每主体保底 ⌊topK/n⌋ 名额，
  轮流出列保各方内部排名，剩余名额按原排名回填；桶内不足配额的主体以
  「本主体名 + 原查询剔除其他主体词」为锚 dense 补召一次，补进桶再重排
- 接线：`VectorStoreKnowledgeRetriever` hybrid 截口（单阶段/rerank 段不接——rerank
  默认关且末端已截到 topN，启用重评时再议）
- 不变量：只在已召回集合内重排+定向补召，绝不发明文档；单主体/无主体查询行为零改变
  （代码层 `subjects.size() < 2` 直通）

**关键实证（Qdrant 直探）**：混合查询 dense 信号被主导方淹没——「贵州茅台+原查询」top-20
仍全宁德；纯主体锚定后召回 100% 归位。这就是锚定查询要剔除其他主体词的原因。

## 低分案归因（既有病灶 vs 新回归）

对照 W21 基线（`docs/eval/generation/logs/w21-tushare-gen.log`）逐案判读：

| 案 | 本轮 | W21 | 归因 |
|---|---|---|---|
| multi-turn「其中的 12987 是什么含义」 | 0/0/2 | 2/2/2 | **抖动显形，非新回归**。改写正常（「贵州茅台酿造工艺中的12987是什么含义」），但混合召回 recallHits=0——全场 57 案唯一一例零召回；守卫单主体直通未介入（代码 `subjects.size()<2` 分支 + 日志无 diversity 行双证）。假设：改写把「12987」与上下文粘连（「中的12987是什么含义」），dense 全低于阈值 0.5 + BM25 分词 miss；对照单轮案「12987 每个数字代表什么」改写带空格（「贵州茅台 12987 酿造工艺中…」）recallHits=20 满分通过。空召回硬拒答是红线设计行为，judge 按「无理由拒答」扣 0/0 属标尺与设计的口径摩擦。该案 W19 起有抖动史。**backlog**：稀疏召回数字粘连分词加固 / 零召回改写重试 |
| in-domain-unanswerable「茅台冰淇淋业务的营收占比」 | 0/2/2 | 1/2/2 | **事实口径抖动，非新回归**。回答结构与措辞边界实际改善（「从本次检索到的内容看，尚未覆盖」），judge 扣准确性在数字口径——引用「2024 营业收入合计 945.27 亿」与参照不符（疑似半年报/母公司口径混用）。grounding 面既有问题，与配额/prompt 无关 |
| multi-turn「为什么不能继续扩」 | 0/0/2 | 0/0/1 | **既有病灶**（赤水河环境容量约束检索不到），略升 |
| factual「宁德时代 2025 年营业总收入」 | 0/0/2 | 0/0/2 | **既有病灶不变**（W22 tushare 批遗留：语料有 2025 年报但检索未命中） |

结论：4 个低分案无一与本次改动（配额守卫 + prompt v3）相关，无新回归。
