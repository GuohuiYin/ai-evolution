## 裁决结论

- **指代案 1/2 稳定修复**：`谁的风险和原材料价格关系最大` R5/R6 均命中（改写正确展开双实体）
- **Recall@5 守线 93% 达成**（27/29 两轮一致，≥93% 计划口径）
- **口径变更注记**：Recall@5 自此为"改写+检索"口径（eval 链路对齐对话通路，"评的就是用的"），
  与 W13 裸检索 93% 数值相等但口径不同，历史比较以本注记为准
