## 三个值得记住的判断

1. **缓存是最大的成本杠杆**：55.8% 命中率省下单次输入约 27%（¥0.0073→0.0054）。
   系统 prompt + 工具定义稳定不动，是缓存命中的前提——prompt 改动要意识到它在冲缓存。
2. **eval 成本可忽略**：一轮全量生成评估 ¥0.17，"每次 prompt 改动跑一轮"毫无成本压力——
   eval-first 在本项目没有成本借口。
3. **Embedding 与重试才是规模化的变量**：当前语料小，摄入近乎免费；
   若未来接真实数据源每日批量摄入，embedding 费用与摄入策略（W8-2 增量机制）才开始显性相关。

## 算账口径说明

- 所有数字可由 `TokenUsageAdvisor` 日志复算：`grep stage=MODEL <log>` 取 tokens_in/out/cache_read
- judge 调用与被测调用同模型同价，未单独折价
- 未含：Qdrant 本地容器（¥0）、SiliconFlow embedding（量级过小）、开发与 CI 机器成本
